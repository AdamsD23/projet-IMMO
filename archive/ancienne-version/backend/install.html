🏠 Installation Accueil Immo CI

Suivez ces étapes pour lancer votre site immobilier complet

📋 Étape 1: Vérifier les prérequis

Assurez-vous d'avoir:

  • XAMPP/WAMP/MAMP installé
  • PHP 8.0+ activé
  • MySQL/MariaDB en cours d'exécution

🗄️ Étape 2: Configurer la base de données

Modifiez le fichier backend/config/config.php:

const DB_HOST = 'localhost';
const DB_NAME = 'accueil_immo';
const DB_USER = 'root';
const DB_PASS = ''; // Votre mot de passe MySQL
